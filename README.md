> **Full Stack Developer | Web Developer | Software Engineer**

A modern, high-performance, responsive personal developer portfolio website engineered with clean vanilla web technologies, dynamic particle background visuals, interactive CLI terminal, dark/light theme switching, and smooth micro-interactions.

---

## 🌟 Key Highlights & Features

- **Cyber-Clean Glassmorphic UI**: Ultra-modern visual aesthetics with ambient glowing accents, smooth backdrop blurs, and responsive typography.
- **Dark & Light Mode Switcher**: Seamless theme switcher with persistent local storage state.
- **Interactive Background Canvas**: Constellation particle field that reacts dynamically to mouse hover and adapts to the active color theme.
- **Interactive Developer CLI Terminal**: Visitors and recruiters can type bash-like commands (`about`, `skills`, `projects`, `experience`, `education`, `hire`, `contact`, `clear`) with clickable shortcut chips.
- **Dynamic Typewriter & Live Code Window**: Real-time role transitions and a code representation card with floating technology badges.
- **Skills Matrix with Category Filter**: Instant filtering between Frontend, Backend, Programming Languages, Databases, Mobile, and Tools/Core CS.
- **Detailed Project Showcases**:
  - **Vision AI**: AI-Powered Learning & Course Platform (Flutter, Dart, Node.js, Express.js, MongoDB, REST APIs, AI API).
  - **TravelBharat**: Indian Tourism Platform (React.js, Node.js, Express.js, MySQL, Netlify).
- **Interactive Experience & Education Timelines**: Highlighting real-world internship impacts (20% load time reduction at Unified Mentor, 15% execution speedup at MEN Solution).
- **Direct Communication & Instant Email Copy**: Contact form with mail client fallback and one-click clipboard copying with toast notifications.
- **Zero Build Step & 100/100 Lighthouse Performance**: Pure HTML5, modern CSS3, and ES6+ JavaScript. Loads instantly with no heavy npm bundles.

## 🚀 How to Run Locally

You don't need Node.js or any build tool to run this project:

1. **Option A: Direct Browser Launch**
   Simply double-click `index.html` in your file explorer or open it directly in Chrome, Edge, Firefox, or Safari.

2. **Option B: Using Python's Built-in Server**
   ```bash
   python -m http.server 3000
   ```
   Open `http://localhost:3000` in your web browser.

3. **Option C: VS Code Live Server**
   Right-click `index.html` in Visual Studio Code and select **"Open with Live Server"**.

## 🌐 Instant Deployment

### 1. Deploying to Netlify (Drag & Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio.akash` folder directly into the browser.
3. Your portfolio will be live worldwide with a custom free HTTPS domain in 5 seconds!

### 2. Deploying to GitHub Pages
1. Initialize Git in the project root:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of modern developer portfolio"
   ```
2. Create a repository on GitHub (e.g. `portfolio` or `<username>.github.io`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/akashkumarsingh-01/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings > Pages** and select `Branch: main`, `Folder: / (root)`. Click **Save**.
